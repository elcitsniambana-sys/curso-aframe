# Pasta `meus-modelos`

Coloque aqui os seus arquivos (modelos `.glb`, imagens, alvos `.mind` do MindAR).

**Como enviar pelo navegador (sem instalar nada):**

1. No GitHub, abra esta pasta (`assets/meus-modelos`).
2. Clique em **Add file → Upload files**.
3. Arraste o arquivo `.glb` e clique em **Commit changes**.
4. Use nos exercícios o caminho `../../assets/meus-modelos/NOME-DO-ARQUIVO.glb`.

**Boas práticas**

- Prefira **.glb** (um arquivo só). Um `.gltf` vem acompanhado de `.bin` e texturas — envie todos juntos.
- Nomes **sem espaços e sem acentos**, tudo minúsculo: `cadeira-escritorio.glb`. O GitHub Pages diferencia maiúsculas de minúsculas!
- Tamanho: ideal até ~5 MB por modelo; o upload pelo navegador aceita até 25 MB por arquivo.
- Anote **autor, fonte e licença** de cada modelo (CC-BY exige crédito visível).
